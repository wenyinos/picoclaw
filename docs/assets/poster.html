Companion

Portable

自由迁移

不保存机器绝对路径；复制 workspace 即可换机。

无需自建前端，直接接入现有聊天软件

把 AI 放进你已经在用的 QQ、微信/企业微信、飞书、钉钉、Telegram、Discord 等客户端；Launcher 只是可选的桌面管理入口。

消息与记忆链路

Gateway → Agent → Memory
QQ / 微信 / 飞书 / 钉钉→ PicoClaw Gateway→ Agent + 工具→ SQLite 记忆→ 模型服务
用户消息→ 规则抽取→ 去重 / 冲突→ 审核队列→ 按预算注入

0.4.1 修复

普通聊天不再进入记忆待审核池；“设定 / 扮演 / 剧情 / 人设”等词不再触发自动记忆，助手回复也不参与抽取。
