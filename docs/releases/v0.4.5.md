# PicoClaw 0.4.5

0.4.5 修复长期记忆的检索链路，并在 Launcher 中增加数据库修复与批量迁移工具。

## 修复

- `memory` 工具的 search 改为跨层检索，默认覆盖 persona / profile / relationship / episodic / procedural / boundary。
- search 支持 `realm` / `layer` / `status` 过滤；生日、画像、关系设定和 private 记忆不再被工具层误过滤。
- 修复任意 query 都返回同一组 work/procedural 记录的问题。
- 提示词检索不再注入相似度为 0 的候选；移除 SQL 预 `LIMIT`，避免较早的相关记忆被截断。
- 提示词检索继续保留 audience、私有渠道和 fictional 隔离；单字中文查询也能命中相关事件。

## 新增

- Launcher `/memory` 增加“数据库修复”页面：按 realm / layer / status / audience / 关键词预览匹配，批量迁移分类。
- 执行迁移前自动用 SQLite `VACUUM INTO` 备份数据库，不删除记录。
- 新增 API：`POST /api/memory/repair/preview`、`POST /api/memory/repair/apply`。

## 升级

- 无数据库 schema 或配置文件结构变更。
- 更新 launcher / gateway 二进制并重启即可。
- 生产数据如果仍是旧的 realm/layer 分布，可以在“数据库修复”页面分批迁移，不需要手写 SQL。
