# PicoClaw 0.3.2

## 更新内容

- **模型**：新增可配置的默认 fallback 链。
- **Pico 渠道**：最终消息返回逐轮 token 用量。
- **QQ**：网关鉴权方案失效时自动重试。
- **工具**：修复 `write_file` 覆盖引导、`exec` 自定义 allow/deny 规则。
- **渠道**：DeltaChat 初步支持；修复 LINE 响应体关闭错误处理。
- **Web**：修复 launcher setup CSRF、pnpm lockfile 重复条目、跨平台路径等问题。
- **发布**：改为仅发布二进制包，停止 Docker Hub 发布。
- **依赖升级**：Anthropic SDK、golang.org/x/crypto、React 相关依赖等。
