# PicoClaw 0.4.1

0.4.1 is a bug-fix release for automatic memory extraction.

## Fixed

- Ordinary chat no longer lands in the memory review queue. The extractor no longer treats common role-play words (`设定`, `扮演`, `剧情`, `人设`, `世界观`, `虚构`, `故事线`) as memory triggers.
- Assistant replies are no longer scanned for memory keywords; only explicit user statements can create memories.
- Automatic extraction is limited to explicit `记住/记一下/别忘了`, preferred names, preferences/allergies, birthdays/anniversaries, and dated events.

## Upgrade

- No configuration or database schema changes.
- Install the 0.4.1 binary and restart the gateway.
- Existing `pending_review` entries created by 0.4.0 are not deleted automatically; review or archive them on the `/memory` page.
