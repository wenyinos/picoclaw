# PicoClaw 0.4.6

0.4.6 修复长期记忆的边界注入：`boundary` 不再和 profile / relationship 抢固定块预算，也不会绕过渠道与虚构隔离。

## 修复

- `boundary` 从固定块预算中独立出来，单独拼接在固定上下文末尾；即使 profile / relationship 很长，边界规则也不会被截断。
- `boundary` 注入增加 `audience` / `private_channels` 过滤：`private` 边界只进入私有渠道。
- `boundary` 注入增加 `inject_fictional` 过滤：未开启虚构注入时，`fictional` 边界不会进入真实对话。
- 保留固定块原有的 token 预算：profile / relationship 仍按预算裁剪，boundary 作为安全块完整保留。
- 新增回归测试：大 profile 不会挤掉 boundary；private / fictional boundary 不会在错误渠道出现。

## 升级

- 无数据库 schema 或配置文件结构变更。
- 更新 gateway / launcher 二进制并重启即可。
- 如果生产库里的 `boundary` 条目仍是长文，建议在 `/memory` 中按“短规则 + 检索层全文”整理；0.4.6 保证短规则不会被预算裁掉，但不会自动压缩历史长文。
