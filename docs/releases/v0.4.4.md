# PicoClaw 0.4.4

0.4.4 修复定时任务的运行时可靠性问题，并补齐直接投递与失败可见性。

## 修复

- 运行中的 gateway 会自动加载 CLI 对 `cron/jobs.json` 的修改，约 500ms 内生效，不再需要重启。
- gateway 停机期间到期的一次性任务会在启动后立即执行一次，不再永久丢失。
- 失败的一次性任务保留为 disabled，写入 `lastStatus`/`lastError`，可通过重新启用立即重试。
- Agent 调用、shell 命令和消息提交失败会真实写入任务状态。
- `cron list` 显示执行模式、上次运行时间、状态和错误信息。
- 配置重载时停止旧的 Cron/Heartbeat 调度器，避免同一任务重复执行。
- `tools.cron.enabled=false` 时，已持久化任务仍会执行；禁用工具只影响 Agent 创建和管理任务。
- 删除最后一个任务后 `jobs.json` 写入 `[]`，不再写入 `null`。
- Cron 日志接入项目 logger，失败和重载信息进入 gateway 日志。

## 新增

- Cron 任务支持 `deliver: true` / `--deliver` 直接投递，不经过 Agent 推理。
- CLI `cron add` 要求 `--channel` 和 `--to`，避免任务执行后没有投递目标。
- 文档补充热加载、过期补执行、失败保留、直接投递和超时说明。

## 升级

- 无配置或数据库结构变更。
- 更新 gateway / launcher 二进制并重启即可。
