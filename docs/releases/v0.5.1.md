# PicoClaw 0.5.1

0.5.1 修复 Launcher 记忆库页面的显示问题，不涉及数据库或配置变更。

## 修复

- 记忆库表格改为固定列宽，状态列不再被挤出容器，重要度列不再被压扁。
- 类型列补充 predicate / facet 展示；长文本截断时保留悬停完整内容提示。
- 记忆详情面板限制最大高度并支持内部滚动，长文本编辑时底部字段仍可访问。
- 详情面板在宽屏下继续吸顶，但不再因为文本域自动长高而把保存按钮挤出视口。

## 升级

- 无数据库或配置文件结构变更。
- 更新 launcher 二进制并重启即可。
