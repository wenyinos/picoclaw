# PicoClaw 0.4.0

PicoClaw 0.4.0 is built around long-term memory and continuity: a SQLite memory store, a dedicated dashboard, and a workspace that can be copied to another machine.

## Highlights

- **Long-term memory in SQLite** (`workspace/memory/memory.db`) with layered entries, exact/near-duplicate detection, conflict superseding, source tracking, and relationship/persona state.
- **Memory dashboard** at `/memory`: overview, search and edit, review queue, relationship/persona editor, and settings.
- **Human-in-the-loop review**: uncertain memories stay in `pending_review` and never enter prompts until approved.
- **Real vs. fictional isolation**: role-play settings are stored separately from the user's real profile and are hidden by default.
- **Private-channel filtering**: intimate memories are injected only into configured private channels.
- **Portable workspace**: no machine-specific absolute paths; `agents.defaults.workspace` accepts a relative path resolved against `PICOCLAW_HOME`.
- **`picoclaw memory` CLI**: import, audit, stats, compact, export, render.
- **Faster response path**: throttled intermediate Pico frames, final frame before persistence, WebSocket write deadlines, pooled provider connections, and asynchronous session JSONL writes.
- **Race fixes** in async sub-turn delivery, channel shutdown, and session API reads.

## Upgrade from 0.3.x

0.4.0 does **not** perform automatic schema migration. Runtime memory lives in `memory.db`, and the old `MEMORY.md` is no longer read.

1. Stop the gateway and launcher.
2. Back up the workspace.
3. Run `picoclaw memory import --from <old-workspace>` (or replace the workspace with a prepared 0.4 workspace).
4. Run `picoclaw memory render` and `picoclaw memory audit`.
5. Start the services and review pending entries at `/memory`.

Full instructions: [Migrating from 0.3.x to 0.4.0](../migration/0.4.0.md).

## Breaking changes

- `workspace/memory/memory.db` is the source of truth for long-term memory.
- Old `MEMORY.md` content must be imported once if it should be preserved.
- Copy or import a workspace while the gateway and launcher are stopped.
