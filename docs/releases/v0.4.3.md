# PicoClaw 0.4.3

0.4.3 修复记忆库页面只显示前 200 条、缺少分页和页面滚动的问题。

## 修复

- 记忆库改为服务端分页，每页显示 100 条。
- 增加“上一页”“下一页”和“第 N 页”显示。
- 搜索或切换领域、类型、状态筛选时，自动回到第 1 页并滚动到列表顶部。
- 请求时额外读取 1 条来判断是否还有下一页，避免最后一页出现空白。
- 记忆页面改为整页滚动，移除表格固定 520px 高度。
- 宽屏下右侧编辑面板保持吸顶，浏览长列表时仍可直接编辑当前选中的条目。
- 所有记录都可以通过翻页和页面滚动访问。

## 升级

- 无配置或数据库结构变更。
- 更新 launcher 二进制并重启即可。
